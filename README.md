# EnglishVidya 📖

Welcome to the official repository of **EnglishVidya** — India's most trusted and modern English learning ecosystem designed specifically for Hindi-medium students. 

## 🌟 About The Project

EnglishVidya goes beyond traditional grammar rules by focusing on **Practical Spoken English**, **Vocabulary Building**, and **Personality Development**. We believe that learning English shouldn't be about memorizing rules, but about understanding the language intuitively.

### Key Features
- 🚀 **Smart Flashcards System:** Interactive vocabulary learning with spaced repetition features.
- 🔊 **Text-to-Speech Audio:** Auto-play audio features to help students learn the exact native pronunciation.
- 📱 **Mobile-First & PWA:** Designed for performance on budget smartphones, complete with Offline PWA support.
- 🧠 **Teacher-Mode:** Built-in floating widgets and presentation modes for educators and schools.
- ⚡ **Lightning Fast:** Built as a static site generator (Eleventy) for maximum speed and SEO optimization.

## 🛠️ Technology Stack
- **Framework:** [Eleventy (11ty)](https://www.11ty.dev/)
- **Styling:** Vanilla CSS (Custom Design System with CSS Variables)
- **Interactivity:** Vanilla JavaScript & Alpine.js
- **Image Optimization:** Sharp (Node.js)
- **Deployment:** Cloudflare Pages (Wrangler)

## 💻 Getting Started (For Developers)

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/Englishvidya.git
   cd Englishvidya
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```
   *The site will be available locally at `http://localhost:3000`*

### Build for Production
To generate the optimized static files for production:
```bash
npm run build:prod
```
The output will be generated in the `_site` directory.
