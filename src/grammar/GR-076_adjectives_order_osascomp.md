# Article 76 — Adjectives Order - The OSASCOMP Rule

### 🎯 Topic Introduction

अगर आपको किसी Noun (संज्ञा) की एक साथ कई खूबियाँ बतानी हों, तो आप किस खूबी को पहले लिखेंगे?
* क्या आप कहेंगे: *"A red big plastic chair"*?
* या आप कहेंगे: *"A big red plastic chair"*?

अंग्रेज़ी ग्रामर में एक से ज़्यादा Adjectives को एक खास क्रम (Order) में रखने का एक पक्का नियम है। इस नियम का शॉर्टकट है: **OSASCOMP**।

---

## 📋 The OSASCOMP Rule (क्रम को याद रखें)

<details>
  <summary>Click to see details (विस्तार से जानें)</summary>

जब एक साथ कई Adjectives आ जाएँ, तो उन्हें इस क्रम में लगाना चाहिए:

**O - Opinion (राय):** आपको वह चीज़ कैसी लगती है? (Beautiful, ugly, good, bad, nice)
**S - Size (आकार):** वह कितनी बड़ी या छोटी है? (Big, small, tall, short)
**A - Age (उम्र/समय):** वह कितनी पुरानी या नई है? (Old, new, young, ancient)
**S - Shape (बनावट):** उसका आकार/शेप कैसा है? (Round, square, flat)
**C - Color (रंग):** उसका रंग क्या है? (Red, black, green)
**O - Origin (मूल/जगह):** वह कहाँ की बनी है? (Indian, Chinese, American)
**M - Material (पदार्थ):** वह किस चीज़ की बनी है? (Wooden, plastic, iron, cotton)
**P - Purpose (उद्देश्य):** उसका काम क्या है? (Sleeping bag, running shoes — यहाँ sleeping और running purpose हैं)

*(नोट: सबसे अंत में वह Noun आएगा जिसकी ये सब विशेषताएँ हैं)।*

**उदाहरण:**
* A **beautiful** (Opinion) **big** (Size) **red** (Color) **wooden** (Material) chair (Noun).
(एक सुंदर बड़ी लाल लकड़ी की कुर्सी)।

</details>

## 🚦 Examples in Action

<details>
  <summary>Click to see details (विस्तार से जानें)</summary>

आइए कुछ वाक्यों को OSASCOMP नियम से सेट करें:

1. *A bag / leather / black / small*
   * क्रम: Size -> Color -> Material
   * सही: **A small black leather bag.**
   * गलत: *A black leather small bag.*

2. *A table / wooden / round / old*
   * क्रम: Age -> Shape -> Material
   * सही: **An old round wooden table.**

3. *A vase (फूलदान) / Chinese / beautiful / tall*
   * क्रम: Opinion -> Size -> Origin
   * सही: **A beautiful tall Chinese vase.**

</details>

## ⚠️ Common Mistakes

<details>
  <summary>Click to see details (विस्तार से जानें)</summary>

### ❌ गलती 1: Size और Color का क्रम बदलना
ज़्यादातर लोग Size और Color को आगे-पीछे कर देते हैं। याद रखें, **Size हमेशा Color से पहले आता है!**
* ❌ *She has a **black long** hair.*
* ✅ *She has **long black** hair.* (Long = Size, Black = Color).

### ❌ गलती 2: Material को Color से पहले रखना
* ❌ *I bought a **wooden brown** table.*
* ✅ *I bought a **brown wooden** table.* (Brown = Color, Wooden = Material).

</details>

## 🎯 Classroom Practice

### अभ्यास: Adjectives को सही क्रम में लगाएँ
1. (Italian / red / fast) car
   → **A fast red Italian car.** (Opinion/Size -> Color -> Origin)
2. (cotton / ugly / old) shirt
   → **An ugly old cotton shirt.** (Opinion -> Age -> Material)
3. (square / small / wooden) box
   → **A small square wooden box.** (Size -> Shape -> Material)

## 📌 Quick Revision

* एक से ज़्यादा विशेषण होने पर **OSASCOMP** नियम लगाएँ।
* **O**pinion → **S**ize → **A**ge → **S**hape → **C**olor → **O**rigin → **M**aterial → **P**urpose + **Noun**.
* **Size पहले, Color बाद में:** Long black hair.
* **Color पहले, Material बाद में:** Brown wooden table.
